Художественный магазин
Учебный проект по дисциплине «Фронтенд и бэкенд разработка» (4 семестр, 2025/2026).
Реализован в рамках Практических занятий 1–5.

Стек технологий
Бэкенд: Node.js, Express, nanoid, cors, swagger-jsdoc, swagger-ui-express
Фронтенд: React, Axios, Sass

Структура проекта
frontend-and-backend-1-6pr-/
├── index.html          # Практика 1 — HTML карточка товара
├── input.scss          # Практика 1 — SASS стили
├── output.css          # Практика 1 — скомпилированный CSS
├── images/             # Скриншоты (Практика 3)
├── PR3-4/
│   └── pr4/            # Практики 4 и 5 — React + Express + Swagger
│       ├── backend/
│       └── frontend/
└── kr1/
    └── backend/        # Финальная версия бэкенда (КР №1)

Функциональность
Просмотр списка товаров
Создание, редактирование и удаление товаров
Карточка товара: название, категория, описание, цена, остаток на складе
Swagger-документация с интерактивным тестированием

Запуск проекта

Бэкенд
cd kr1/backend
npm install
node app.js
Сервер запустится на http://localhost:3000
Swagger UI доступен по адресу http://localhost:3000/api-docs

Фронтенд
cd PR3-4/pr4/frontend
npm install
npm run dev
Приложение откроется на http://localhost:3001

API эндпоинты
Метод	Путь	Описание
GET	/api/products	Список всех товаров
GET	/api/products/:id	Товар по ID
POST	/api/products	Создать товар
PATCH	/api/products/:id	Обновить товар
DELETE	/api/products/:id	Удалить товар

1 Практика
Реализовала карточку товара (содержимое: название, описание, фотография) с применением переменных, миксина и использованием вложенной структуры селекторов SASS.

2 Практика
Реализовала API, которое предоставляет CRUD операции для списка товаров (просмотр всех товаров, просмотр товара по id, добавление товара, редактирование товара, удаление товара). Объект товара содержит следующие поля: id, название, стоимость.

3 Практика
Протестировала API из Практического занятия 2 с помощью Postman (не менее 3-х запросов). Выбрала внешнее API, получила ключ, изучила документацию и выполнила не менее 5-ти запросов.

4 Практика
Доработала рассмотренный пример: два приложения на React и Express (для клиента и сервера, соответственно), связанных в единую систему — сайт интернет-магазина товаров. Количество товаров — не менее 10. Карточка товара содержит: название, категорию, описание товара, цену, количество на складе.

5 Практика
Доработала задание из практического занятия №4: подключила swagger-jsdoc и swagger-ui-express, описала с помощью JSDoc-аннотаций схему товара и все CRUD-операции (GET, POST, GET/:id, PATCH/:id, DELETE). Убедилась, что документация доступна по адресу /api-docs и работает в интерактивном режиме (можно отправить тестовый запрос).

6 Практика
В данной работе было сделано всё, что требовалось по заданию. Проект полностью готов к сдаче Контрольной работы №1. Репозиторий содержит все практики, а также готовый проект. Итоговый проект находится в папке kr1. В нём реализованы все функции. Также создан файл README.md, в котором кратко описываются все процессы.
